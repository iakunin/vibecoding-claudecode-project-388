# Проект: Трекер цен с Claude — Шаг 4

Источник: https://ru.hexlet.io/projects/388/members/53773?step=4

## Скилл tracker: батч → таблица

Теперь собираем скилл `tracker`, который работает не с одним URL, а со всем списком сразу. Список отслеживаемых URL зашит внутри самого скилла.

`tracker` проходит по списку, для каждого URL вызывает скилл `extract-price` и собирает все результаты в единую таблицу (товар → цены). Так из набора одиночных извлечений получается один цельный прогон.

## Задачи

1. Создайте второй скилл — `tracker` в `.claude/skills/tracker/SKILL.md`. В `description` обозначьте, что он обходит список URL и собирает таблицу цен; позже сюда добавятся хранение, diff и Telegram.
2. Зашейте список отслеживаемых URL прямо в тело скилла (тот, что вы собрали на первом шаге). Так трекер запускается одной фразой, без ручного перечисления ссылок каждый раз.
3. Опишите главный сценарий: для каждого URL из списка ассистент вызывает уже готовый скилл `extract-price` и получает объект цены. Подчеркните, что `tracker` переиспользует `extract-price`, а не дублирует его логику.
4. Опишите сборку результатов в единую таблицу прогона: одна строка на товар, в строке — URL и поля `regular_price`, `sale_price`, `has_credit`. Это будущая запись прогона.
5. Запустите `tracker` и убедитесь, что за один запуск он проходит весь список и отдает цельную таблицу по всем товарам, а не по одному.

## Результат шага

Скилл `tracker` за один запуск обходит зашитый список URL, вызывает `extract-price` для каждого и формирует единую таблицу прогона (товар → цены) по всем товарам сразу.

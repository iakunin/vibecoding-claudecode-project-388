# Проект: Трекер цен с Claude — Шаг 3

Источник: https://ru.hexlet.io/projects/388/members/53773?step=3

## Скилл extract-price

На этом шаге создаем первый и самый базовый скилл — `extract-price`. Это универсальный кирпичик: на вход он получает один URL страницы товара, а на выход отдает структурированные данные о цене.

Результат работы скилла — объект вида `{ regular_price, sale_price, has_credit }`: обычная цена, цена по скидке (если есть) и признак доступности рассрочки. Здесь же знакомимся с форматом скилла (`SKILL.md`): как описывается назначение, вход и выход.

## Ссылки

- Agent Skills — документация Claude — формат `SKILL.md` и как Claude решает, когда применить скилл.

## Задачи

1. Создайте скилл `extract-price` в `.claude/skills/extract-price/SKILL.md`. Скилл — это упакованный сценарий: описание в начале файла (`name`, `description`) и инструкция в теле.
2. В `description` опишите назначение скилла одним-двумя предложениями так, чтобы Claude Code понимал, когда его применять: «извлекает цену товара с одной страницы по URL».
3. Зафиксируйте контракт прямо в теле скилла: вход — один URL страницы товара; выход — объект `{ regular_price, sale_price, has_credit }` (обычная цена; цена по скидке или `null`, если скидки нет; `true`/`false` для рассрочки).
4. Опишите ассистенту логику извлечения: как получить содержимое страницы (загрузить HTML, при необходимости — парсинг), где искать цену, как нормализовать число и валюту (убрать пробелы и символы, привести к числу), что делать, если цена не найдена.
5. Проверьте скилл на 2–3 URL из вашего списка: попросите Claude Code применить `extract-price` и убедитесь, что на выходе именно объект контракта, а не текст в свободной форме.

## Результат шага

Есть рабочий скилл `extract-price`: по одному URL он возвращает строго структурированный объект `{ regular_price, sale_price, has_credit }`. Скилл проверен на нескольких реальных страницах из вашего списка.

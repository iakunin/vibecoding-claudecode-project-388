## Sub-agent на Haiku (опционально)

Финальный необязательный шаг — оптимизация по стоимости. Генерация текстовой сводки для Telegram не требует мощной модели, поэтому ее можно делегировать более дешевой.

`tracker` передает diff и правила оформления sub-agent'у на модели Haiku, а тот возвращает готовый короткий текст для отправки. Основная модель занимается логикой, дешевая — формулировкой сводки.

## Задачи

1. Выберите для сводки дешевую модель: форматирование готового diff в короткий текст — простая задача, мощная модель тут не нужна. Подходящий кандидат — быстрая и дешевая Haiku.
2. Настройте sub-agent на модели Haiku, которому `tracker` делегирует только одну работу — превратить список значимых изменений в аккуратную короткую сводку для Telegram.
3. Передайте sub-agent'у входные данные (diff) и правила оформления (формат строки, длина, эмодзи — по вкусу), получите готовый текст и отдайте его в `send.py`. Основная модель при этом занимается логикой трекера, дешевая — только формулировкой.
4. Сравните результат: качество сводки от Haiku против сводки, собранной основной моделью, и разницу в стоимости. Зафиксируйте для себя, оправдана ли оптимизация на вашем объеме прогонов.

## Результат шага

Текстовая сводка для Telegram генерируется отдельным sub-agent'ом на Haiku: основная модель отвечает за логику трекера, дешевая — за формулировку сводки. Вы понимаете выигрыш в стоимости и его цену в качестве.

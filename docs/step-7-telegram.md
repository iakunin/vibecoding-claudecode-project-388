# Проект: Трекер цен с Claude — Шаг 7

Источник: https://ru.hexlet.io/projects/388/members/53773?step=7

## Публикация diff в Telegram

Значимые изменения полезнее получать сразу в мессенджере. На этом шаге подключаем доставку результатов в Telegram.

Шаг состоит из двух подэтапов. Сначала вы сами регистрируете бота через @BotFather и проверяете, что он готов вам писать. Затем по вашему запросу Claude создает скрипт `send.py` (на стандартном `urllib`, без внешних зависимостей), а `tracker` формирует короткую сводку по значимым изменениям и отправляет ее через этот скрипт. Так как скрипт использует только стандартную библиотеку, ничего устанавливать не нужно: в облачном окружении Python уже есть, а запускает скрипт сам ассистент.

Бота создаете вы руками в Telegram — Claude этого сделать не может. На выходе у вас должны быть две строки: токен бота и ваш chat id, а сам бот — готов прислать вам сообщение.

## Ссылки

- @BotFather — регистрация бота и получение токена.
- @userinfobot — быстрый способ узнать свой chat id.
- Telegram Bot API — методы бота, в том числе `sendMessage`.

## Задачи (подэтап 1: бот)

1. В Telegram найдите @BotFather, отправьте команду `/newbot`, придумайте имя — в ответ получите токен (строка вида `1234567:AA...`). Скопируйте его.
2. Узнайте свой chat id: напишите боту @userinfobot — он пришлет числовой id (либо используйте метод `getUpdates` из Bot API).
3. **Важно:** откройте чат со своим новым ботом и отправьте ему любое сообщение (например, `привет`). Без этого бот не сможет написать вам первым — сообщения от него не дойдут.
4. Сохраните токен и chat id как `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Самый простой способ — попросить Claude создать файл `.env` с этими строками; обязательно добавьте `.env` в `.gitignore` — ключи и токены нельзя коммитить в репозиторий. Если работаете в облачном окружении с разделом Secrets/Variables, токен можно положить туда: тогда файл `.env` не нужен вовсе, а `send.py` возьмет значения из переменных окружения.

> Бот зарегистрирован, токен и chat id у вас на руках (в `.env` или в Secrets окружения), и вы уже отправили боту первое сообщение. Если токен где-то засветился — сразу отзовите его в @BotFather командой `/revoke` и заведите новый.

## Задачи (подэтап 2: скрипт send.py и доставка)

Теперь нужен скрипт, который отправит текст в Telegram, и связка его с `tracker`. Python-код руками писать не нужно — скрипт генерирует ассистент.

1. Попросите Claude создать скрипт `send.py` для отправки сообщения в Telegram: он использует только стандартную библиотеку Python (`urllib`), без внешних зависимостей, и берет токен и chat id из переменных окружения (или из `.env` рядом). Запуск: `python send.py "текст"`.
2. Проверьте отправку отдельно: `python send.py "тест"`. Должно произойти два события: в выводе — `Отправлено.`, а в Telegram от бота — сообщение `тест`. (Если Claude скажет, что `python` не найдена — попросите `python3 send.py "тест"`.) Не приходит — вернитесь к подэтапу 1: чаще всего вы не написали боту первым или в `.env` неверный chat id. Третья возможная причина — сеть облачного окружения, про нее ниже.
3. Дополните `tracker`: из списка значимых изменений он формирует короткую человекочитаемую сводку (одна строка на изменение) и отправляет ее через `send.py`. Если значимых изменений нет — договоритесь, шлет ли трекер «Значимых изменений цен нет» или молчит.
4. Запустите трекер и убедитесь, что сообщение со сводкой пришло в Telegram.

> Если работаете в облаке на claude.ai/code, первая отправка может упереться в сеть окружения. Облачная сессия по умолчанию ходит только по разрешенному списку адресов, и `api.telegram.org` в него не входит — скрипт при этом не жалуется ни на токен, ни на chat id, а просто не может достучаться до Telegram. Лечится в настройках окружения: нажмите кнопку с названием окружения над полем ввода, откройте настройки, в разделе Network access выберите Custom, добавьте `api.telegram.org` в список разрешенных доменов и оставьте включенным флажок про список по умолчанию — иначе отвалятся пакетные менеджеры. После этого начните новую сессию. На своем компьютере такого ограничения нет.

## Результат шага

Бот зарегистрирован, токен и chat id не хранятся в репозитории, скрипт `send.py` рабочий. Значимые изменения цен приходят отдельным сообщением в Telegram.

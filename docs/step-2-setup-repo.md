# Проект: Трекер цен с Claude — Шаг 2

Источник: https://ru.hexlet.io/projects/388/members/53773?step=2

## Постановка и репозиторий

Суть проекта понятна — пора заложить фундамент. Репозиторий проекта уже выдан платформой, в нём вы и работаете. На этом шаге определяемся, что и зачем отслеживаем, и готовим репозиторий к работе со скиллами.

Нужно выбрать нишу (например, видеокарты, кофемашины, конкретный маркетплейс) и собрать список URL страниц товаров, за ценами которых будем следить.

Открыть проект можно прямо в браузере на claude.ai/code — без локального клонирования и без установки тулчейна: в облачном окружении уже есть и Python, и git, так что отдельно ничего настраивать не нужно.

## Ссылки

- Claude Code в браузере — как открыть репозиторий и работать в облаке без локальной настройки.
- MCP в Claude Code — как подключать MCP-серверы, в том числе GitHub по личному токену.

## Задачи

1. Выберите нишу, цены в которой вам интересно отслеживать. Подойдут любые товары со стабильными страницами: видеокарты, кофемашины, конкретный маркетплейс, авиабилеты на популярном направлении. Запишите в свободной форме, зачем вы это отслеживаете — это поможет дальше формулировать задачи ассистенту.
2. Сформулируйте, что именно считается «ценой» в вашей нише: обычная цена, цена по скидке, наличие рассрочки. Эти три величины станут контрактом будущего скилла.
3. Соберите стартовый список из 5–10 URL страниц товаров. Проверьте каждую страницу по двум критериям «хорошей» для трекера: ссылка стабильная (не содержит временных параметров сессии) и цена видна сразу, без логина и без действий вроде «положить в корзину».
4. Подключите репозиторий Хекслета к Claude Code и попросите агента сделать заготовку для будущих скиллов — папку `.claude/skills/`.
5. Заведите приватный репозиторий `tracker-data` — в нем будет копиться история прогонов, отдельно от кода скиллов. На github.com: New repository → Private → Add a README. Наполнять его будет трекер, этим займемся на шаге про сохранение прогонов.
6. Подключите GitHub MCP к Claude Code — через него трекер будет писать в `tracker-data`. Порядок подключения разбирали в курсе, в уроке про Claude Code: коннектор из claude.ai виден в Claude Code по команде `/mcp`, а если его там нет или приходит ошибка 403, сервер подключают по личному токену. Токен нужен fine-grained, с доступом только к репозиторию `tracker-data` и правами Contents: Read and write и Metadata: Read-only. Шаг сделан, когда `/mcp` показывает сервер `github` в статусе connected.

> Если ошибка 403 приходит и с валидным токеном, значит доступ к GitHub MCP вашему аккаунту не выдан — это ограничение на стороне GitHub, обойти его нельзя. Тогда сохраняйте прогоны обычным git с тем же токеном: на требования проекта это не влияет, меняется только способ записи в репозиторий.

## Результат шага

Есть репозиторий проекта, подключенный к Claude Code, с пустым каркасом `.claude/skills/` в первом коммите. Заведен приватный репозиторий `tracker-data`, подключен GitHub MCP по личному токену — `/mcp` показывает сервер `github` как connected. Зафиксированы выбранная ниша, список из 5–10 URL и определение «цены» (обычная / по скидке / рассрочка), на которое будет опираться скилл `extract-price`.

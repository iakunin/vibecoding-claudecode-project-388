# Проект: Трекер цен с Claude — Шаг 1

Источник: https://ru.hexlet.io/projects/388/members/53773?step=1

## Чему учимся

В этом проекте мы собираем рабочий инструмент почти без ручного кода: основная логика живет в Claude-скиллах и вызывается из Claude Code. Это и есть вайбкодинг — вы ведете диалог с ассистентом, формулируете требования и принимаете решения, а рутину делегируете ИИ.

Работать будем в Claude Code, и проще всего — прямо в браузере на claude.ai/code, без установки чего-либо на свой компьютер. Программировать и знать git не нужно: вы формулируете задачи словами, а код пишет и запускает ассистент. Единственный кусочек «кода» в проекте — крошечный скрипт для Telegram — тоже создает Claude, и он работает на стандартной библиотеке Python, так что ставить зависимости не придется.

Проект учит складывать готовый автоматизированный сценарий из переиспользуемых скиллов: от извлечения одной цены до регулярной сводки изменений в мессенджере. По пути вы подключаете внешние сервисы через MCP, храните историю прогонов в отдельном GitHub-репозитории и оптимизируете стоимость, делегируя простую работу дешевой модели.

## Описание проекта

«Трекер цен на Claude-скиллах» — автоматический трекер цен на товары, собранный целиком на скиллах. Вы выбираете нишу и список товаров, а трекер сам обходит страницы, сохраняет прогоны, сравнивает их с прошлыми и присылает значимые изменения в Telegram.

Ниша полностью на ваш выбор — подойдут любые товары со стабильными страницами (видеокарты, кофемашины, конкретный маркетплейс, авиабилеты на популярном направлении). Главное, чтобы цена была видна без логина.

## Что вы сделаете

- Скилл `extract-price` — по одному URL возвращает `{ regular_price, sale_price, has_credit }`
- Скилл `tracker` — обходит список URL, вызывает `extract-price` и собирает таблицу прогона
- Хранение прогонов в отдельном приватном GitHub-репозитории `tracker-data` (файлы `YYYY-MM-DD.json`) — запись и чтение через GitHub MCP, подключенный по личному токену
- Сравнение с прошлым прогоном (diff) и правила значимости изменений в `KNOWLEDGE.md`
- Уведомления о значимых изменениях в Telegram
- Опционально — генерация TG-сводки sub-agent'ом на дешевой модели (Haiku)

В результате у вас останется переиспользуемый скилл (скиллы), который сам обходит список товаров, сохраняет прогоны, сравнивает их и присылает изменения в Telegram.

## Задачи

1. Разберитесь с идеей проекта: мы собираем инструмент почти без ручного кода — основная логика живет в скиллах, а вы управляете процессом из диалога с Claude Code.
2. Представьте итоговый сценарий целиком: обход списка URL → таблица цен → сохранение прогона в отдельный приватный репозиторий через GitHub MCP → сравнение с прошлым прогоном → сводка значимых изменений в Telegram.
3. Прикиньте, что предстоит собрать своими руками в выданном репозитории: скиллы `extract-price` и `tracker` в `.claude/skills/`, правила значимости в `KNOWLEDGE.md` и helper `send.py` для Telegram. Готовых заготовок нет — каждый кусок вы создаете по шагам в диалоге с Claude Code.

## Результат шага
